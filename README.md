# GoldBrain MT5 Windows preflight

Read-only technical preflight for official MetaTrader 5 on a standard GitHub-hosted Windows runner. It compiles an MQL5 source that calls CopyTicksRange for XAUUSD over a 10-minute Oct 9, 2026 interval. Live trading is disabled. No credentials, private GoldBrain models, or raw CSV tick data are committed or uploaded. Only executable availability and tick counts are printed.

**Not a licensed training dataset, nor an OOS trading edge.** GitHub-hosted standard Actions on public repositories are free, and the workflow has a 12-minute timeout.
